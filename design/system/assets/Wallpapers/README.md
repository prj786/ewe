# Wallpapers

The wallpapers that ship with ewe: near-black grounds with one soft, off-center glow and a faint sheep watermark in the lower-right corner.

- `ewe-flock.jpg`: neutral grey, the calmest; pairs with any accent.
- `ewe-dark.png`: flat charcoal with the watermark.
- `ewe-dawn.jpg`: a warm, dim red glow; the closest to Ewe's gold.
- `ewe-blue.jpg`, `ewe-indigo.jpg`, `ewe-meadow.jpg`: cool blue, violet and green glows.

New wallpapers follow the same rules as the `gradient-*` tokens: dark, slight, a single glow and no busy imagery, so the bar and panels always sit on a quiet background. Add the watermark in the lower-right corner, never over the center.
