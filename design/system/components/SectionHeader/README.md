# Section header

A section header names a group of settings or list items, with an optional description and action.

## Anatomy
1. Title: 15px weight 600 in `text-primary`, or the `overline` style in `text-muted` right above a list.
2. Description (optional): 13px in `text-secondary`.
3. Action (optional): a secondary Button or a Link, aligned to the bottom right.

## Spacing
- 24px above a section header and 8px between it and its content.
- The first header on a page has no space above it.

## Do and don't
- Do use the overline form for short labels directly above a list well.
- Don't end titles with a colon or a period.

## Accessibility
- Titles are headings at the level below the page title.

## What a build provides
`title` · `description` · `variant` (title, overline) · `action`.
